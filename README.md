# Descomplica CLT — Sistema Educacional para Totem Touchscreen

Sistema web educacional desenvolvido para aplicação de quizzes interativos em totens verticais touchscreen (proporção 9:16), integrado a painel administrativo unificado para gestão de temas, perguntas com feedbacks gerais ou individuais por alternativa, importação via Word (`.docx`) e relatórios de desempenho.

Consulte `docs/INSTALACAO_E_DEPLOY.md` para instruções de migração, instalação e deploy.
